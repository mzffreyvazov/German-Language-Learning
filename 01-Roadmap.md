# Roadmap

## Next lessons
### L002 — Essential Greetings and Courtesies
- type: topic
- status: planned
- description: Covers the closed set of core greeting and parting formulas (hallo, guten Morgen/Tag/Abend, auf Wiedersehen, tschüss), key politeness markers (danke, bitte, Entschuldigung), and standard yes/no responses. Samples common introductory conversational questions. Builds immediate communicative competence using L001 sounds.

### L003 — Personal Pronouns & Present Tense of 'sein' and 'haben'
- type: grammar
- status: planned
- description: Covers the complete closed set of all 9 German subject pronouns (ich, du, er, sie, es, wir, ihr, sie, Sie) and the full present tense conjugation paradigms of the two core irregular auxiliary verbs 'sein' (to be) and 'haben' (to have). Contrasts pronoun distinctions with English, Turkish, and Azerbaijani.

### L004 — Basic Sentence Structure & Regular Present Tense Verbs
- type: grammar
- status: planned
- description: Covers the complete closed set of regular present tense verb inflection endings (-e, -st, -t, -en, -t, -en) with standard weak stems. Teaches the fundamental Verb-Second (V2) syntax rule in main declarative clauses and inverted yes/no question word order.

### L005 — Core Nouns, Gender & Definite/Indefinite Articles
- type: grammar
- status: planned
- description: Covers the complete closed set of nominative definite articles (der, die, das) and indefinite/negative articles (ein, eine, ein / kein, keine, kein), along with universal noun capitalization rules. Samples the primary noun plural patterns (-e, -er, -en/-n, -s, umlaut).

### G001 — Familiarization Gate
- type: gate
- status: planned
- description: Evaluates spelling-to-sound mastery, recognition of foundational vocabulary, basic reading comprehension across 2-3 short passages, and V2 word order recognition. Marks successful completion of the familiarization phase and transition to the loop phase.
- gate: G001
